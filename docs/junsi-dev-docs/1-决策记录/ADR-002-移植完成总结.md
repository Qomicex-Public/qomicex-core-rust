## 技术债（后续处理项）

1. `Error::Http` 无 status 字段（CurseForge 400 判定用消息文本匹配）
2. Windows 系统 DNS 用 ipconfig 解析近似（locale 脆弱，可换 winreg/NDIS）
3. SRV 端口丢失（trait resolve_srv 只返回目标）
4. Directory 创建失败静默（Rust 构造无法传播）
5. `parse_minecraft_datetime` 仅 ISO-8601 子集
6. NBT HashMap 键序随机（规范合法，写回顺序不稳定）
7. `get_data_dir` 宿主约定 QOMICEX_HOME（Android 需宿主设置）
8. CacheExpiry/MaxConcurrentDownloads 选项未透传（源同样未用）
